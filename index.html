Our research directions

Open questions. Clear tests.

We focus on research problems where rigorous evaluation matters more than chasing complexity.

01 / EVALUATION

Reliable model evaluation

Stress-testing models, probing baselines, studying failure cases, and designing measurements that tell the truth.

02 / MULTIMODAL

Reasoning across modalities

Investigating how systems use text, images, video, and structure when a task demands more than pattern matching.

03 / SYSTEMS

Practical research systems

Building lightweight, reproducible workflows that make experiments understandable, repeatable, and useful.

How we work

Start small.
Know more.

Interesting results need strong controls. We value methods that are easy to explain, compare, and reproduce.

01
Baseline before breakthrough

Begin with the simplest defensible reference, then earn every added layer of complexity.

02
Inspect the misses

Use error analysis and targeted evaluations to discover what a model actually learned.

03
Keep experiments reproducible

Document settings, decisions, limitations, and artifacts so claims can be independently checked.
